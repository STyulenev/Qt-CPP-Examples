# Catch2-Example

## Описание

Пример использования библиотеки тестирования Catch2.

[Ссылка на исходники Catch2](https://github.com/catchorg/Catch2 "Catch2")

## Сборка

### CMake:

Собрать проект (cборку можно производить из QtCreator или из папки build командами):

### CMake:

```bash
cmake ..
make
```
> Для debug - "cmake -DCMAKE_BUILD_TYPE=Debug ..", для release - "cmake -DCMAKE_BUILD_TYPE=Release .."
